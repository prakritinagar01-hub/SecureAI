# 🛡️ SecureAI — AI-Powered Security Intelligence Platform

SecureAI is an AI-powered cybersecurity assistant designed to analyze suspicious messages, URLs, and AI security threats. It helps users identify potential risks through intelligent analysis and clear security reports.

## 🚀 Features

### 1. Message Security Scanner
- Analyzes suspicious messages.
- Detects phishing attempts and social engineering patterns.
- Classifies threats into High, Medium, and Low risk levels.

### 2. URL Security Scanner
- Accepts URLs for security analysis.
- Identifies suspicious URL patterns.
- Generates detailed security reports.

### 3. AI Security Lab
- Tests AI systems against prompt injection attempts.
- Detects malicious or misleading instructions.
- Evaluates AI security risks.

### 4. Security Dashboard
- Displays total scans.
- Shows risk-level statistics.
- Maintains recent scan history.
- Provides security activity insights.
